SUMMARY

Your chosen website on every new tab, with the address bar ready to search.

DESCRIPTION

Open your own start page whenever you create a new tab, while keeping Firefox's
address bar empty and ready for typing. Use your existing default search engine.

Choose a website in settings. Ordinary links open in the full tab, including
links that initially request a new window. Ctrl-click, middle-click, downloads
and in-page fragment links retain their usual behavior. Glance dashboard group
headings are supported too.

Returning with Back restores supported standard tabs, expandable sections and
scroll positions for that browser tab. Glance groups use the same standard tab
handling. Firefox may still reload the site. Custom application state and
changed layouts are not guaranteed to restore.

There are no accounts, subscriptions, analytics, or developer-operated servers.
Your selected address is stored locally. Website access is requested only for
the site you choose. The extension is open source under the MIT license.

Compatibility: desktop Firefox 140 or newer. Your chosen start page must allow
embedding. Some sites block embedded pages, and this extension respects those
protections. Some website-script buttons, logins, cookies and autofocus may
behave differently inside an embedded page. If your chosen site redirects to
another hostname, save its final address.

RELEASE NOTES

Version 1.0.4 makes Back/Forward view restoration work across sites using standard
ARIA tabs, native expandable sections, and ARIA accordions with labelled regions.
Glance groups continue to work through the same standard tab handling. Stable
element IDs improve restoration when content moves. Horizontal right-to-left
scrolling is supported. Restoration stops on user input and avoids repeated
activation of unresponsive controls. No new permissions are required.

REVIEWER NOTES

No compilation, minification, runtime dependencies or remote extension code. All
extension code is in the release ZIP. Remote websites are loaded as web content
inside an iframe, chosen explicitly by the user; they do not receive privileged
extension APIs. Security headers are not altered. The extension never changes
Firefox's security settings.

Required permission: storage. HTTP(S) hosts are declared as optional so a user
can choose a website; only the chosen scheme/hostname is requested at runtime.
The page script authenticates through the extension background before handling
links. Authorization checks the owning tab, frame, origin, per-session token
and current site permission. Normal top-level website visits are unaffected.

View snapshots contain only the selected page URL, standard control states,
DOM element IDs/paths/types and scroll coordinates. They remain in bounded background memory,
scoped to a tab and configured site, and are cleared on tab closure, site change
or permission revocation. Page HTML, form values and arbitrary app state are
never retained. No history API permission is requested. Cached documents
disconnect on pagehide and reconnect on pageshow; reloaded documents request
their latest saved view only for a Back/Forward navigation.

Restoration recognizes ARIA tabs linked to tabpanels, native details sections,
and ARIA disclosure buttons linked to a region labelled by that button. It does
not infer actions from CSS classes or replay arbitrary clicks. It checks the
current control semantics again before restoring, skips active controls and
form-submit/popup actions, and suppresses anchor navigation during restoration.
Retrying stops after five seconds or immediately on user input. Controls without
the supported markup and arbitrary JavaScript app state are not restored.

The source package includes 46 automated tests and a pnpm lockfile. jsdom is a
development-only dependency used by HTML fixture tests, not extension code.
Use the README's installation and test commands to run the suite. No test
dependencies or generated code are included in the release ZIP.

To test, install the extension, open a new tab, choose a website that permits
embedding, save and allow access to that site. Open another new tab and follow
an ordinary link. The destination should replace the full tab. No account or
private dashboard is needed. The README describes architecture and validation.
