USE

After installation, open a new tab, select Choose website, enter a website
address and select Save website. Grant access to that chosen site when Firefox
asks. No website is configured by default. Existing users keep their saved site.

On a fresh new tab the extension displays that website in an iframe, leaving
the new-tab address bar empty. Ordinary links open in the full tab. Ctrl-click,
middle-click, downloads and in-page fragment links retain native behavior.
Glance's active linked group headings are supported too.

Back/Forward navigation restores the most recent Glance group selections,
Show more list/grid expansion states and page/panel scroll positions for that
browser tab. Generic control restoration from 1.0.4 has been removed.
State is temporary, bounded background memory, cleared on tab closure, site
change or revocation. It is not shared between tabs or stored on disk.
Firefox can still reload the page before restoration. This is not native page
caching. Changed layouts, feed content and arbitrary website application state
are outside the restoration guarantee.

The chosen start page must permit embedding. Websites that prohibit embedding
remain blocked, and those protections are never disabled. Login, cookies,
autofocus and buttons driven entirely by website JavaScript may behave
differently when embedded. Use the final address after any cross-host redirects.

REQUIREMENTS AND DEVELOPMENT

Desktop Firefox 140 or newer. For temporary development installation, open
about:debugging#/runtime/this-firefox, choose Load Temporary Add-on and select
extension/manifest.json. Temporary installation lasts until Firefox restarts.
Permanent installation in ordinary Firefox requires Mozilla's signature.

The internal add-on ID is retained from the original Clear New Tab prototype
so existing users can update without losing their saved website. Public-facing
branding is Tab & Type.

CONTENTS

extension/ is the complete, dependency-free add-on source. There is no build
step. The distribution ZIP contains only those files, with manifest.json at its
root. tests/ executes the actual packaged scripts using Node's built-in test
runner, mocked browser APIs and jsdom HTML fixtures with simulated scrolling.

Run from the repository root with Node 22.22.2+, 24.15.0+, or 26+ and pnpm 11.25.0:
    pnpm install --frozen-lockfile --ignore-scripts
    pnpm test
jsdom is a development dependency only; nothing in node_modules is packaged.

DESIGN / MOZILLA REVIEWER NOTES

The extension uses chrome_url_overrides.newtab to serve a local HTML page, with
the user's selected HTTP(S) page in an iframe. It never redirects the new-tab
document on initial load or tries to manipulate Firefox's address-bar UI.

The only required permission is storage. HTTP(S) host patterns are declared as
optional so the user can choose any supported website. The options page requests
one exact hostname/scheme, then releases the previous hostname on a change.
No tabs, webNavigation, webRequest, nativeMessaging, or clipboard permission is
requested. The tabs API is used only for the current extension tab's ID and
navigation of the authenticated tab; those operations need no tabs permission.

The persistent Manifest V2 background registers a document_start content script
only for the selected host. Top-level pages and nested frames exit immediately.
A direct child frame must authenticate against a live port from this extension's
own new-tab document before its click or submit handlers take action. Background
requests are checked against tab ID, frame ID, exact origin including port, a
per-session token and current host permission. Snapshot messages require the
same authorization and are restricted to bounded view-state fields whose URL
matches the sending frame. Ordinary visits to the site are
unaffected. No page postMessage or page-injected privileged API is exposed.

Trusted, unmodified left-clicks on HTTP(S) anchors navigate the full tab using
tabs.update, including anchors initially marked _blank. Glance's active group
headings (button.widget-group-title-current[data-title-url]) are also handled.
Fragment links, downloads and modified clicks keep native behavior.
Native form targets become _top while preserving method,
encoding and body. JavaScript-only navigations and custom form routers are not
guaranteed. Security headers and signature-check settings are never modified.

All executable extension code is packaged, readable, original source; no bundler,
remote code, runtime dependencies, or compilation is involved. The add-on has no telemetry or
data collection. A user-selected website is loaded directly as ordinary web
content, subject to that site's own behavior and privacy policy.

GLANCE VIEW RESTORATION

page-view.js restores the 1.0.3 group-selection and scroll behavior:
- .widget-type-group contains a .widget-header with button.widget-group-title
  children; the selected title has .widget-group-title-current.
- Groups are identified by child-element path, and the title by its index.
- Inactive titles invoke the dashboard's handler; active linked titles are
  never clicked during restoration.

Version 1.0.5 adds Glance's Show more/less controls:
- .list.collapsible-container[data-collapse-after], or
  .cards-grid.collapsible-container[data-collapse-after-rows].
- A nonnegative integer collapse limit and an immediate following sibling
  button.expand-toggle-button are required. Disabled, inert, editable and
  form-submit controls, formaction and data-title-url buttons are excluded.
- Both expanded and collapsed states are saved as booleans, including sections
  inside inactive groups. The container's .container-expanded class is read.
- If restoration needs a change, the toggle is clicked at most once per DOM
  element. This updates Glance's internal expanded variable, both CSS classes
  and the Show more/less label together. No class-only imitation is performed.
- Group selection and expansion happen before page/element scroll restoration.

The serializer retains at most 64 groups, 128 expansion states and 128 scrolled
elements per view. Paths contain at most 32 child indexes. Coordinates retain
the 1.0.3 bounds (zero to ten million). The background keeps at most 200 tab
snapshots. No text labels, HTML, form values or arbitrary script data are saved.
Paths rely on a consistent document layout; inserting/reordering widgets can
prevent restoration or associate a saved path with a different matching widget.

Restoration waits for DOMContentLoaded, retries for at most five seconds and
stops after five stable checks or on trusted user input. Delayed widget markup
and generated toggle buttons can arrive during the retry period. Other sites'
ARIA tabs, details, accordions and arbitrary application state are not restored.
Snapshots require the authenticated frame and token. The 1.0.3 click/scroll and
navigation capture behavior is retained.

Glance reference:
https://github.com/glanceapp/glance/blob/main/internal/glance/static/js/page.js

The wrapper retains its defensive cached-pageshow handling, but that is not
proof of native cache eligibility. Firefox's multiple-top-level-context rule
can exclude extension pages sharing a browsing-context group with a persistent
background page. No Firefox caching or security settings have been changed.

VALIDATION STATUS

All 38 Node tests pass using mocked Firefox APIs and jsdom HTML fixtures, including
regressions for the dashboard's target rewriting and linked group headings.
Back/Forward regressions cover simulated cached and reloaded wrapper documents,
Glance groups, Show more lists/grids and working Show less afterward, hidden
group sections, expansion before scrolling, unsafe/changed controls, delayed
widgets, user interruption, bounded retries, tab isolation, revocation,
snapshot validation and renewed bridge authorization.
Timing and scrolling are simulated; jsdom does not reproduce Firefox layout,
browser UI or its history cache. These new
changes have not yet been tested in a live Firefox session.

The link behavior was tested in real Firefox 159 with an isolated, headless
profile and a Glance dashboard. A Hacker News article link and the Hacker News
group-heading button both navigated the top-level tab and loaded successfully.
The new-tab address bar was empty. Keyboard focus was not confirmed by the
headless test; the original user subsequently confirmed the extension worked
in their normal Firefox window. Version 1.0.0 adds release branding, the MIT
license, privacy documentation and a blank default website field.
Version 1.0.1 replaces the typing-cursor icon with a browser tab and search
symbol. Extension behavior is unchanged.
Version 1.0.2 removes the custom favicon from the new-tab page, leaving the
tab icon to Firefox. The settings page and add-on keep their branded icons.
Version 1.0.3 adds temporary view restoration after Back/Forward navigation
and reconnects cached frames without resetting their document or click state.
Version 1.0.4 replaces Glance-specific restoration with standard HTML/ARIA
control handling, stable IDs, bounded activation and generic DOM regressions.
Version 1.0.5 returns to 1.0.3 restoration and adds Glance Show more/less state.
Version 1.0.5 has not been submitted for Mozilla signing / AMO review.
